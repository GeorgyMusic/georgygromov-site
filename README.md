# georgygromov.com

Рабочий репозиторий личного сайта Георгия Громова. Ведёт Импресарио, правки обсуждаются в Telegram.

## Структура

| Папка | Что внутри |
|---|---|
| `design/` | варианты дизайна: каждый в своей подпапке, с собственным index.html |
| `content/` | тексты разделов в markdown, отдельно от вёрстки |
| `assets/` | изображения, шрифты, видео |
| `index.html` | текущая рабочая версия главной |

## Как мы работаем

1. Георгий говорит, что менять, в Telegram.
2. Импресарио правит файлы и отправляет изменения сюда.
3. Через минуту-две правка видна по ссылке предпросмотра.
4. Публикуем на домен только после явного «да».

## Разделы сайта (черновик структуры, уточняется)

- Главная: кто такой Георгий, одной фразой и доказательствами.
- Дирижирование: репертуар, оркестры, дирижирование от рояля. Репертуарный список нужен на немецком.
- Фортепиано: соло и дуэт с Марией.
- Коучинг и выступления: форматы для компаний и конференций, мастер-класс с живым оркестром.
- Просвещение: курсы, лекции, ретриты.
- Пресса и материалы: фотографии, биография, райдер, видео.
- Контакты.
